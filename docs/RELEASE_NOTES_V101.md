NDS4MiSTer v1.0.1

What’s new

* Improved FMV playback, including native-speed openings in Castlevania: Dawn of Sorrow and Portrait of Ruin.
* Updated menu fonts and spacing for better readability in DV1 Top/Bottom view (TATE mode)
* Fixed Castlevania Dawn of Sorrow bug that could cause “Save failed” error.

Known issues

* You may still see slowdowns, stutter, audio hitches or graphical glitches, and a steady 60 FPS isn’t guaranteed.
* Save states, wireless multiplayer and DSi mode aren’t supported yet.

Install

1. Exit NDS with System → Reboot, then back up saves/NDS and Scripts/.NDS.
2. Extract the full ZIP to the root of your SD card, including hidden files. Merge folders and replace package files.
3. Run Scripts → NDS.
4. On a fresh install, choose your display settings and use System → Save settings.
