# RC13 validation scope

RC13 promotes the tested Regional Beta9 runtime to the normal standalone installation paths. Host, renderer, FPGA, guest catalog, movie hooks and loader are retained byte for byte. The supervisor receives only the release text update; launcher support paths change to the normal installation. No new gameplay performance claim is assigned to packaging.

Beta9's actual archive passed complete virtual-image comparisons for Platinum USA rev0, FFT Europe fallback, Portrait of Ruin FMV and New Super Mario Bros. Its native installation smoke covered a cold Platinum USA rev0 launch through cartridge startup. The Touch host had already passed input regression tests and a native synthetic-device Touch/drag check. Physical controller compatibility is not exhaustively tested.

Regional qualification is bounded to documented scenes and lifecycle checks. Four Platinum ports (Italy, Spain, Japan and Korea) were included at the user's explicit request without completing gameplay validation. See VERSION_COVERAGE.md and the game reports in the source archive. No full-playthrough or bit-exact RAM/audio certification is claimed.

The package audit verifies every checksum, runtime pins, nested source contents, original frozen build-input inventories, guest identities, movie hooks, launcher guards and preservation of existing settings/saves. The final archive has not been relaunched on hardware; qualification is inherited through exact runtime identity. RC13_EVIDENCE_INDEX.json identifies the prior records, and RC13_OFFLINE_VALIDATION.json records representative worker image results.
