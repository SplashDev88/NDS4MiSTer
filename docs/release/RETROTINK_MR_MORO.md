# Mr. Moro's RetroTINK-4K profiles

Optional profiles supplied courtesy of **Mr. Moro**. Download
`NDS4MiSTer_RetroTINK4K_MrMoro_Profiles.zip` separately from the core installer.
The supplied ZIP and its profile files are preserved unchanged.

## Install on the RetroTINK SD card

Merge the contents of the ZIP's `NDS4MiSTER` folder into the root of the
**RetroTINK-4K SD card**. Keep the existing folders and other profiles:

- `profile/MiSTer/NDS/NDS Default.rt4`
- `profile/MiSTer/NDS/NDS Rotate.rt4`
- `profile/MiSTer/NDS/info.txt`
- `image/MrMoro/NDS.bmp`

Load the desired profile from the RetroTINK's profile browser. These files
belong on the RetroTINK card, separately from the NDS4MiSTer install on MiSTer.

## Settings from Mr. Moro's included notes

**NDS Default:** intended for the core's default setup and for
**Direct Video Target → Scaler**. His notes also describe analog use with
one DS screen.

**NDS Rotate:** intended for a physically rotated display. Set the core's
**Direct Video Target → Scaler** and **Video Rotation → 90 CCW** or
**90 CW**, matching the display orientation. Mr. Moro specifically says
to leave the RT4K Pro's **RoTATE** function off for this profile.

These are contributor-supplied display profiles. Their archive integrity and
contents were checked during RC14 preparation; a fresh hardware/profile test
was not performed. They do not add dual-screen rotation to the core's native
analog output. For a CRT through a Y/C DAC/adapter, use the separate CRT-target
instructions in `QUICK_START.txt`.
