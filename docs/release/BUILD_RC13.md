# RC13 corresponding source and reproduction

NDS4MiSTer-rc13-source.tar.gz is the committed release source. It contains host, supervisor, loader, guest catalog/hooks, renderer, kernel-module source, package tooling and vendored libraries. Runtime revisions and hashes are recorded in manifest.json and BUILD_PROVENANCE.json.

## Host

The tested host already has the rc13 label and is reused without recompilation. Its frozen inputs and command are included as Regional_Host_source.tar.gz, Regional_Host_inputs.json and Regional_Host_BUILD.sh. To reproduce it, build the container from tools/Dockerfile.mister-armhf (Ubuntu 24.04, GCC 13.3). The tested local image ID was sha256:b196be9f1d989f2388969ae8ba89c447db2792c46c90eb2b4554fa2fee4941bc. Mount release source read-only at /src and an output directory at /out, then run RC13_HOST_BUILD.sh. This runs both host tests and produces the Cortex-A9/NEON, hard-float static C++17 O2 executable. Copy it into tools/standalone_host/nds_standalone_host before packaging. core_menu.h is generated by generate_menu.py from VERSION. RC13_HOST_LABEL_VALIDATION.json records exact identity with the accepted Beta9 host.

## Renderer and dependencies

The accepted renderer is reused without recompilation. Its original source is also included as Regional_Renderer_source.tar.gz, with Regional_Renderer_inputs.json, Regional_Renderer_build.json and Regional_Renderer_BUILD.sh. The release source's compiled renderer inputs are unchanged from that source revision.

Build included FFmpeg 7.1.1 using tools/build_fmv_ffmpeg.py --target armhf. Mount the install at /evidence/vx-research/combined-arm-install, renderer source at /work, and counters from portrait-combo3-pgo.tar.gz at /tmp/nds-portrait-combo3-pgo. Run Regional_Renderer_BUILD.sh in the cross-build container. Preserve /work/build-armhf: profile paths are encoded in GCC counters. Partial-training and coverage-mismatch fallback are intentional. Renderer self-tests run in the container, never on a live MiSTer. No new HPS service or RTL is introduced.

## Loader and guest patches

The packaged Python/assembly/JSON loader inputs match the committed source. Existing generated hooks are retained with exact hashes. Rebuilding hooks uses tools/standalone_host/fmv/build_guest.py and the existing ARM toolchain. guest_catalog.json contains only the accepted selections; the install launcher pins its hash. No commercial game data is supplied or needed to build these tools.

## FPGA

side-native-fpga-inputs.tar.gz is the exact retained FPGA source tree. RC11_FPGA_INPUTS.json inventories all 1,978 files; RC11_FPGA_BUILD.json records the original build and unresolved timing. Use Quartus 17.0 with its archived NDS4MiSTer project/constraints/settings. No new FPGA build was performed for rc13.

## Package

From a clean committed release checkout with the tested host and generated guest binaries restored from the authenticated beta input:

    python3 tools/package_rc13_release.py --beta-zip /path/to/NDS4MiSTer_Regional_Beta9_20261101.zip --out-dir /path/to/new-output

Packaging authenticates the immutable accepted beta input (SHA-256 6aad40a987eafb757e8e802c8247f7960f56b641b2881e14b0ca0d3c3f878e02), reuses its qualified runtime/dependencies and emits the normal standalone installation layout. That archival input is a maintainer artifact; corresponding component sources and build recipes are included independently in this release. The command has no publication step. To audit a finished ZIP:

    python3 tools/package_rc13_release.py --audit /path/to/NDS4MiSTer_v0.9.0-rc.13_Standalone.zip

Only reviewed release notes and sanitized provenance are exported. Private evidence paths, recordings, ROMs, saves, personal settings and unused trial manifests are excluded from the installation tree.
