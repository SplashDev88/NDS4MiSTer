NDS4MiSTer v1.0.2

What’s new

* Modest speed improvements and bug fixes.
* **Ultimate Mortal Kombat 3** and **Resident Evil: Deadly Silence** now run at or near full speed.
* **GTA: Chinatown Wars** runs 20% faster.
* **Tokimeki Memorial Girl's Side: 3rd Story** now boots.
* Fixed background tearing in **New Super Mario Bros.** World 1-2.

Known issues

* Slowdowns, stutter, audio hitches and graphical glitches may occur, and steady 60 FPS isn’t guaranteed.
* Save states, wireless multiplayer and DSi mode aren’t supported yet.

Install

1. Exit NDS with System → Reboot, then back up saves/NDS and Scripts/.NDS.
2. Extract the full ZIP to the root of your SD card, including hidden files. Merge folders and replace package files.
3. Run Scripts → NDS.
4. On a fresh install, choose your display settings and use System → Save settings. AA starts Off; saved preferences are preserved on upgrades.
