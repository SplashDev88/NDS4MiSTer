NDS4MiSTer

Extract the entire ZIP to the SD card root, including Scripts/.NDS/.
Put uncompressed .nds games in games/NDS/.
Run Scripts -> NDS. The version is shown in the core menu.
Choose Load *.NDS to play. No BIOS or firmware files are needed.
Use System -> Save settings to keep display and controller preferences.
Exit with System -> Reboot before updating or powering off.

Updates keep the same Scripts/NDS.sh launcher and Scripts/.NDS/ folder.
Existing RC14/RC15 settings, controller mappings and the clock import on
first launch. Existing .NDS settings take priority.
Back up saves/NDS/ and Scripts/.NDS/NDS_rtc.cfg.

See README.md for controls and display setup.
