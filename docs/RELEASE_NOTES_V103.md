# NDS4MiSTer v1.0.3

## What’s new

* Improved performance in games including Final Fantasy III (17->29 FPS), Mario & Luigi: Bowser’s Inside Story (11->18 FPS), Golden Sun: Dark Dawn (14->19 FPS), Radiant Historia (22->24 FPS), GTA: Chinatown Wars (17->19 FPS), and Metroid Prime Pinball (40->58 FPS).
* Final Fantasy III and Metroid Prime Pinball are both at or near native speed.
* Bug fixes in Golden Sun: Dark Dawn
* Fixed stylus movement on DS4/DS5 controller touchpads. Added adjustable touchpad sensitivity in the NDS menu from 100% to 400%.

## Install

1. Exit NDS with System → Reboot. Back up saves/NDS and Scripts/.NDS.
2. Extract the full standalone ZIP to the root of the SD card, including hidden files. Merge folders and replace package files.
3. Run Scripts → NDS.
