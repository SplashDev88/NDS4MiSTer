The exact GTA1 FPGA loaded on MiSTer is packaged without rebuilding. The ARM
helper, Kickstart, WC module and their checksum files are identical to v0.5.2.
Only release documentation and manifests change after the compiled revision.
The on-screen build text was intentionally retained to preserve that binary.

GTA reads GXSTAT position-stack level and pops that many entries each frame.
The prior FPGA returned zero, allowing stack-pointer drift and recurring wrong
camera/stray-triangle/black-3D frames. InsaneFriend's fix tracks normalized
MTX_MODE/PUSH/POP on acceptance, exposes the position/projection/error fields,
and implements the stack-error acknowledgment. The seven production source
and build files match the supplied archive byte-for-byte, including seed 5.
The archive identifies original commit 70c75f9 but contains no Git history;
we credit the author without presenting that as a locally verified commit.

Tracker scope is submission-order state, not precise geometry execution
latency. Matrix busy, polygon/vertex counts and STORE/RESTORE slot-31 error
semantics are not expanded. No packet ABI, rendering schedule, clock, ARM
round trip, buffer depth, command acceptance or CPU/DMA backpressure changes.
Rare near-camera clipping remains separate from the recurring GTA scene bug.
See docs/INSANEFRIEND_GTA_STACK_PORT.md for contributor evidence and limits.

Local validation: supplied FIFO/frame-CDC/delayed-scanline/sparse-phase tests;
128 GTA-style frame-start POP sequences; DMA/direct normalization; stack error,
acknowledgment/reset and register byte-lane tests; existing GX readback/reply
regressions; full console VHDL analysis; complete map/fit/asm/sta build.
All tracked build input hashes were verified after compilation. The user
requested packaging after GTA1 was loaded. No full-playthrough, new measured
GTA event count, all-game speedup or universal 60 FPS claim is made.

Resources: 38,938/41,910 ALMs, 42,563 registers, 530/553 M10K, 54/112 DSP.
Compared with v0.5.2: +36 ALMs, +39 registers, unchanged M10K/DSP.
Worst setup -20.773 ns, hold -0.204 ns. Timing is NOT closed. All 12 console
hold-summary slacks improve over the accepted FPGA; this does not establish
closure or operation on every device. Contributor clean-hold results were
not reproduced by this local build. No new compile is performed for packaging.

Production settings remain stock 1 GHz, WC on compatible kernels, matrix-prefix
fast, 100-us query polling, packet-NC=0, standard palette cache, upload snapshots,
matched full-rate display and weighted dual-core raster. Normal diagnostics
and timing profiling remain disabled. Engine B On and Off are supported;
Off hides second-engine content. The normal MiSTer frontend is retained.

All prior FFT startup/menu, NSMB, Pokemon Platinum, InsaneFriend compatibility,
Castlevania and Metroid display, Chrono startup/movie/sprite, saves/touch/TATE
and disconnected Linux Wi-Fi retry fixes remain. Strange Journey intro freezes,
occasional GTA clipping, movie/audio hitches, slowdown and game-specific issues
remain. SoulSilver has not been independently verified. No DS wireless multiplayer.
