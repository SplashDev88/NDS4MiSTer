This beta adds independent native analog/digital displays, complete-release
controller mapping and a shared persistent game clock. DS CPU execution,
audio and DS timing stay in FPGA; the existing ARM graphics renderer remains.
Matched-frame drawing blocks are pruned and save-profile lookup is supplied by
the host. These changes do not add save states, DS wireless or DSi mode.

Static timing reports setup -13.834 ns and recovery -14.351 ns, with incomplete
constraints. Bounded hardware results do not establish timing closure or broad
stability. Physical CRT/controller/adapter coverage, long sessions and multiple
boards remain incomplete. Native output is approximately 59.64 Hz, not PAL 50 Hz.
RTC alarms/periodic interrupts and save-state clock restoration are unsupported.

Public launch paths are Scripts/NDS4MiSTer.sh and Scripts/.NDS_Standalone.
Merge the ZIP into an existing installation without deleting saved settings.
No ROMs, BIOS/firmware dumps, saves, maps, personal settings, credentials, test
captures or kernel image are bundled. Keep all files from one release together.

Upload assets: the tested install ZIP and its SHA-256 companion. Corresponding
source uses GitHub's automatic source archives at the release tag. Retain all
licences and notices, including FreeBIOS and tools/standalone_host/THIRD_PARTY.md.
