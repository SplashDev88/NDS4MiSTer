NDS4MiSTer v0.3.0-beta.12 source — optional Engine B

This source snapshot accompanies NDS4MiSTer_Public_Beta_v0.3.0-beta.12_20260911.
Engine B defaults Off to retain the fast single-screen path. Enable Engine B
in the core menu, then Reset or reload the ROM to apply the change. On restores
the second graphics engine but costs speed and can lag under heavy load.

Production ARM source: 48d8bce4290b4525f22a9e9bcc9dbcb1c3ed4545
Production FPGA source: 4bb276cae44768794736007e882538bb22ae552d
The ARM revision contains exactly the same FPGA sources as the FPGA revision.
Only README.md, SOURCE_PACKAGE.txt, and the source SHA256SUMS manifest change
for packaging. The accepted Test3 FPGA, ARM helper, and launcher are reused
byte for byte. The installed core is renamed to NDS_20260911.rbf.

Included changes
----------------
- Optional ARM-rendered Engine B with an Off/On session policy. Off avoids its
  rendering/snapshot work and retains the accepted 3D-only fast path.
- The registered reset-release qualifier for reliable startup is retained.
- A bounded Engine B refresh under sustained emergency catch-up prevents all
  eligible refreshes from being skipped indefinitely. It completes before
  successor packets replace the current snapshot. Incomplete/discarded geometry
  and future snapshots remain ineligible; Off render admissions are unchanged.
- Antialiased shadow frames retain the exact Y raster split because X clipping
  loses coverage updates. Non-AA X splitting, adaptive splitting, and bands stay.
- Latest accepted ARM renderer work, including constant-color span/depth reuse,
  transparent shading improvements, adaptive catch-up, replay worker wakeup
  correction, parallel shadow/stencil rendering, specialized antialias final
  pass, direct plane publication, and frontend CPU0 pinning.
- Kirby extended-palette, local ARM9 VRAM write retirement, disabled Engine B
  register readback, and standard-palette fade/text-color fixes.
- ARM9 halt/IRQ-resume correction, sound-bias correction, touch calibration and
  pointer, EEPROM/FRAM/Flash saves, and InsaneFriend's writable firmware, ARM7
  Wi-Fi boot-memory, and cartridge-IR compatibility work. Wi-Fi register
  compatibility does not provide networking.

Deferred work and limits
-----------------------
The experimental GX readback path remains excluded because it caused substantial
slowdown. It supplies the clip-matrix and BOX_TEST results needed by missing
Pokemon player/furniture graphics, so those objects can remain missing:
https://github.com/SplashDev88/NDS4MiSTer/issues/16

Beta.11's transparency improvements remain. No additional 3D speed percentage
is claimed for beta.12. Locality-cache and stateless-rendering experiments were
implemented and measured on MiSTer; neither showed a repeatable useful net gain,
so they are excluded. No credits menu was added. ARM remains at 1 GHz.

Engine B On can refresh slowly and lag under load. Hardware publication counts
and snapshot age are not measurements of live gameplay FPS or input latency.
No claim is made that all games run at full speed or that graphics, saves, audio,
or crashes are universally fixed. Audio remains experimental; networking,
microphone, NAND saves, and save states are not implemented.

Validation
----------
The maintainer accepted the exact Test3 pair after TV testing. Hardware checks
covered NSMB Engine B On, Castlevania Off and On, and a final cold NSMB Off
startup. Session policy matched, guest and published rendered frames advanced,
and transport faults stayed zero. The tested ARM clock was 1 GHz.
Host and ARM tests passed for the bounded refresh, unchanged Off admissions,
future/discard/reset guards, paired publication, and exact AA shadow output.
Earlier transport, snapshot ownership, Off equivalence, reset, palette, and
ARM9 halt/IRQ regression evidence is retained with the development record.

Map, fit, assembly, and timing analysis completed. Fit: 41,196 ALMs, 493 RAM
blocks, 69 DSP blocks. Worst setup: -13.340 ns; worst hold: -0.555 ns;
worst recovery: -8.844 ns. Timing closure is not claimed. The accepted binaries
were not rebuilt for packaging. Simulation, hashes, and source checks do not
establish universal stability or game speed.

Source contents and licensing
-----------------------------
Contains the tracked FPGA/ARM sources, build and test scripts, generated-image
source for the free boot code, and component license/attribution files.
Commercial ROMs, console BIOS/firmware dumps, personal saves, credentials,
