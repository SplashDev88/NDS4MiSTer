Build entry points
- FPGA: fpga/mister_nitro_console_island/NDS4MiSTer.qpf; Quartus Prime
  17.0.2 Build 602 Lite, Cyclone V 5CSEBA6U23I7. Use the checked-in QSF
  and frozen input manifest. The FPGA was not rebuilt for rc.8.
  tools/check_rtc_synthesis.py checks retained RTC synchronizers.
- Host: tools/standalone_host/build.sh; GCC 13.3.0, static C++17 -O2,
  Cortex-A9 NEON hard-float. VERSION and the menu identify v0.9.0-rc.8.
- Renderer: tools/build_hybrid_3d_service_armhf.sh; GCC 13.3.0, static
  Release -O3/LTO, Cortex-A9 NEON hard-float. The accepted renderer is retained.
- Kernel modules: kernel/nds_mem_wc, including configuration and provenance
  for 5.15.1-MiSTer and 6.18.38-MiSTer. The launcher selects the matching ABI.
- Installer: tools/package_standalone_release.py. Supply the matching core,
  host, renderer and both modules. --check-only checks those inputs. To reproduce
  the ZIP, use the packaging-source revision recorded in its manifest and the
  exact pinned binary inputs. A source archive accepts --source-revision.
  tools/audit_public_release.py checks the ZIP and sidecar against source pins.

The release contains separate analog/digital screens, complete-release controller
mapping and a persistent DS game clock. DS CPU execution, audio and DS timing
remain in FPGA; the ARM graphics renderer is retained. Matched-frame drawing
blocks are pruned and the host supplies save-profile lookup. Save states, DS
wireless and DSi mode are not added.

Static timing remains unresolved: setup -13.834 ns and recovery -14.351 ns, with
incomplete constraints. Routing and bounded tests do not establish timing closure
or broad stability. Physical CRT/controller/adapter coverage, long sessions and
multiple boards remain incomplete. Native output is approximately 59.64 Hz,
not PAL 50 Hz. RTC alarms/periodic interrupts are unsupported.

The rc.8 host has software/build checks; hardware qualification was performed
on the split.8.6 host before its version-label-only rebuild. See validation
for that distinction. No physical hardware retest is claimed for relabeling.

Public launch paths: Scripts/NDS4MiSTer.sh and Scripts/.NDS_Standalone.
