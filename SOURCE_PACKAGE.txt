This release retains the 1 GHz ARM clock and frame skipping off. It includes
Castlevania-specific rendering/scheduling improvements, full-rate NSMB drawing,
offline RTC startup and the inherited save/graphics compatibility fixes. DS
CPU execution, audio and DS timing remain in FPGA; graphics run on ARM. Separate
analog/digital layouts and release-aware controller mapping are retained.

Routing and assembly passed; static timing closure remains unresolved. No new
timing analysis or hardware test was performed for public packaging. Earlier
Beta12 live checks and private-kit installation smoke are inherited. The public
layout has offline archive/merge/rollback checks, not a new physical launch.
Long sessions, all games, physical adapters and multiple boards remain incompletely
tested. Native analog is approximately 59.64 Hz, with no PAL 50 Hz mode. Save
states, persistent lid-close resume, wireless, DSi and RTC alarms are unsupported.

Public launch paths: Scripts/NDS4MiSTer.sh and Scripts/.NDS_Standalone.
Merge the ZIP without deleting saved settings. No ROMs, BIOS/firmware dumps,
saves, maps, personal settings, credentials, captures or kernel image are bundled.
Keep all files from one release together. The install ZIP and SHA-256 companion
are the release assets; corresponding source uses GitHub's archives at the tag.
Retain included licences and notices, including FreeBIOS and
tools/standalone_host/THIRD_PARTY.md.
