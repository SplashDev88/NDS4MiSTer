Required configuration and architecture
--------------------------------------
Use the supplied core/helper/launcher together. Engine B must be On; Reset or
reload the ROM after enabling it. Existing Off configurations are not changed
by the installer and must be updated through the core menu. The matched
protocol rejects an incomplete Off stream, which can leave a blank display.
Kickstart enables MATCHED_DISPLAY_TEST, MATCHED_DISPLAY_FULL_RATE,
WEIGHTED_RASTER_BANDS, DUAL_CORE_3D, ADAPTIVE_RASTER_SPLIT, RASTER_BAND_QUEUE and
RASTER_X_PARTITION with their NDS4MISTER_ prefix. WC defaults enabled.
DIRECT_PLANE_PUBLICATION remains set but is ignored by matched mode.

FPGA CPU, sound, input, cartridge, save and LCD event paths remain. ARM renders
both 2D screens and 3D into complete pairs, adopted through acknowledged frame
banks. Native FPGA pixel writes are disabled in this configuration. B row
caching, packed BG rows, effective-write revision tracking, span optimizations
and weighted dual-core raster bands are included. All guest records replay;
obsolete drawing may be omitted under load. Full-rate mode removes the mandatory
alternate-frame skip; it does not guarantee every frame is drawn or 60 FPS.
WC Device control and pixel mappings remain separate. An incompatible optional
module falls back to Device pixel transfers. No overclock, kernel replacement,
permanent boot hook, save replacement or automatic INI/CFG edit is included.

Validation and limitations
--------------------------
The exact MATCH4 helper passed host and emulated ARM full self-tests in default
and weighted modes, plus a focused physical MiSTer full-rate test. That focused
test checked 20 consecutive pairs / 1,966,080 pixels; 816 input frames with
58 draws / 5,701,632 pixels through five backlog recoveries; and concurrent
1024 input frames / 4 draws / 196,608 pixels with delayed ACK and immutable
published banks. The 24-case admission model is synthetic, not game timing.
Earlier MATCH1 helper failed a hardware test; its later MATCH4 replacement is
the helper in this release. Do not confuse the shared FPGA with that old pair.
Packaging verifies source/hash identity, frozen test evidence, complete source
archive, launcher lifecycle and required environment, installer content/modes,
internal/outer checksums and public-source/history audits. No new hardware
qualification is performed during packaging.

Several graphical regressions remain. Castlevania bottom-screen black flashes
are unresolved. Strange Journey can still freeze during its intro. Movies and
audio can hitch, and game-specific slowdown, missing graphics or crashes remain.
The slower Pokemon GX readback correction remains deferred. Engine B Off is
unsupported. Frame-publication counters do not measure unique displayed FPS.
No universal compatibility, input-latency, 60 FPS or hitch-free claim is made.

FPGA fit: 37349 ALMs needed, 39369 placed, 4138/4191 LABs, 447 M10K, 54 DSP.
Worst setup -16.142 ns; hold +0.082 ns; recovery -11.148 ns; removal +0.317 ns.
Timing is not closed. Resource changes reflect moving screen composition to
ARM, not an equivalent reduction with the previous FPGA display architecture.
