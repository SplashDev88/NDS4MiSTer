NDS4MiSTer v0.9.0-rc.7 — Standalone

Prepared locally for release review. Packaging does not publish anything.
The source tree contains corresponding sources, licences and build scripts
for all shipped components; private development data is not required.

The exact full-featured CLEAN1 FPGA tested on 2026-10-12 is retained. It fixes
native CRT presentation at 262 lines, removes temporary FPGA probes, and retains
all display/gameplay features with a bit-exact nearest-scaler refactor.
The exact public rc.6 host and renderer binaries remain unchanged. The host's
compiled version label and tools/standalone_host/VERSION therefore stay rc.6.
The rc.7 package and supervisor identify the release; EXPECTED_CORE pins the
new hardware-tested FPGA. No gameplay clocks or runtime speed options change.

Build and validation records:
  docs/RELEASE_BUILD_V090_RC7.json
  docs/FPGA_BUILD_V090_RC7.json
  docs/FPGA_SOURCE_INPUTS_V090_RC7.json (all 1,328 frozen FPGA inputs)
  docs/HARDWARE_VALIDATION_V090_RC7.json
  docs/STANDALONE_FRONTEND_BUILD_V090_RC6.json (unchanged host inputs)
  docs/RUNTIME_INPUTS_V090_RC7.json
Top-level SHA256SUMS covers every tracked source file except itself.

Build entry points:
- FPGA: fpga/mister_nitro_console_island/NDS4MiSTer.qpf; Quartus Prime
  17.0.2 Build 602 Lite, Cyclone V 5CSEBA6U23I7, seed 7,one fitter worker.
  The fixed input manifest identifies the accepted RBF; no release rebuild.
- Host: tools/standalone_host/build.sh; GCC 13.3.0, static C++17 -O2,
  Cortex-A9 NEON hard-float. VERSION remains rc.6 for exact correspondence.
  See docs/STANDALONE_FRONTEND_BUILD_V090_RC6.json for compiler/source pins.
- Renderer: tools/build_hybrid_3d_service_armhf.sh; GCC 13.3.0, static Release
  -O3/LTO,Cortex-A9 NEON hard-float. Accepted 913 inputs retained.
- Kernel modules: kernel/nds_mem_wc ; source/config/build provenance for
  5.15.1-MiSTer and 6.18.38-MiSTer. Matching ABI selected automatically.
- Installer: tools/package_standalone_release.py;provide matching core,
  host,helper and both modules. --check-only verifies inputs without a ZIP.
  tools/audit_public_release.py checks the ZIP and checksum against source.

Native RGBS 240p, DV1, ordinary HDMI, TATE/menu rotation, scaled RGBHV VGA and bounded
NSMB gameplay, audio, Peek and lid checks passed. Physical CRT acceptance remains
pending. Composite/S-video physical output and game-specific synthetic mic
interaction were not requalified. See the hardware record for limits.
Static timing is diagnostic only; negative slack does not block this package.

Public launch paths remain Scripts/NDS4MiSTer.sh and Scripts/.NDS_Standalone.
Merge the archive without deleting the existing directory. No personal
settings, controller maps, ROMs, BIOS/firmware dumps, saves, credentials or diagnostic
captures are bundled. Normal MiSTer/Console/Kickstart installations remain.
The separate newer all-controller mapping beta is not included.

Only the install ZIP and SHA-256 companion are release assets. Matching
source will use GitHub's automatic source ZIP/tar.gz at the release tag.
No duplicate source ZIP asset is needed. Retain all included licences and
attributions, including FreeBIOS and tools/standalone_host/THIRD_PARTY.md.
