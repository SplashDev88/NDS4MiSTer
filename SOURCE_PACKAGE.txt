NDS4MiSTer v0.9.0-rc.5 — Standalone

Local release candidate prepared for review. Not published by packaging.
The public tree includes complete corresponding project sources for each
shipped component. Private development paths/history are not prerequisites.

The exact tested beta.7 FPGA binary is packaged, adding lid sleep/wake and
synthetic microphone blowing. The frontend includes menu-only lid control,
hold-to-blow input, DualSense motion/trigger fixes, independent touch rotation
for sideways games, and browser/menu improvements.
Only its version label changes for release. The renderer, both Linux
write-combining modules, 1 GHz clock setup and runtime speed options remain
unchanged. Public launch paths remain Scripts/.NDS_Standalone. Normal
Console/Kickstart installations and user files are preserved.

Component identities, build tools and validation limits are recorded in
  docs/RELEASE_BUILD_V090_RC5.json
  docs/FPGA_BUILD_V090_RC5.json
Source content is verified by the top-level SHA256SUMS. It includes every
tracked source file except itself. docs/FPGA_SOURCE_INPUTS_V090_RC5.json records
the matching FPGA, RTL and third-party inputs from the tested hardware build;
current frontend sources and their separate receipt describe the release label
update. Private test data and diagnostic captures are not build inputs and are
excluded from the public tree.

Build entry points:
- FPGA: fpga/mister_nitro_console_island/NDS4MiSTer.qpf, Quartus Prime
  17.0.2 Build 602 Lite, Cyclone V 5CSEBA6U23I7, seed 6. The embedded build
  label remains 260930-LR2; the SHA-256 identifies the actual accepted RBF.
- Renderer: tools/build_hybrid_3d_service_armhf.sh, GCC 13.3.0,
  Cortex-A9 NEON hard-float, static Release -O3 with LTO. All 913 corresponding
  source inputs match the accepted PF3 renderer exactly.
- Frontend: tools/standalone_host/build.sh, GCC 13.3.0, static C++17 -O2,
  Cortex-A9 NEON hard-float. tools/Dockerfile.mister-armhf is included. A
  newly resolved distribution toolchain may not be byte-identical to the
  recorded container. generate_menu.py reproduces the standalone Load *.NDS
  label and reads every option bit/row from the matching FPGA CONF_STR.
- WC module: kernel/nds_mem_wc includes source, config, GPL-2.0 licence,
  build scripts and BUILD_PROVENANCE*.json for 5.15.1-MiSTer and
  6.18.38-MiSTer (SMP mod_unload ARMv7 p2v8). The launcher selects the
  matching binary. Do not force-load another ABI.
- Installer: tools/package_standalone_release.py accepts matching compiled
  component files and this source tree, verifies pinned identities, and emits
  the public Scripts layout plus documentation and checksums. --check-only
  performs no staging. See --help for all inputs.

The public launcher checks prerequisites, manages SPI/process ownership,
initializes only missing private settings and restores normal MiSTer on a
handled exit. Its install archive contains no personal configuration, maps,
commercial ROMs, BIOS/firmware dumps, saves, credentials or diagnostic captures.
The included FreeBIOS and generated game firmware are open-source/synthetic;
optional native GUI files must be supplied separately by the user.

Only the install ZIP and its SHA-256 companion are release assets. Matching
source will use GitHub's automatic source zip/tar.gz links at the release tag.
No duplicate source ZIP is needed. Retain LICENSE.txt, all vendored licences
and tools/standalone_host/THIRD_PARTY.md, including FreeBIOS attribution.
InsaneFriend (saneFriend) attribution for existing compatibility and GTA fixes
is retained. The later Jackass, King Kong and NFS Carbon bundle is not included.
