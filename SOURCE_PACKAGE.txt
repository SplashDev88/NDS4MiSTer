The FPGA, renderer and WC module are packaged without rebuilding or changing
runtime rendering/pacing options. The frontend includes its release label
update and the isolated ROM-loading fix from
1644284466634f53feafb2307e7d11577ef6f3d2. Slow file reads run in a
disposable worker, while the parent keeps its existing watchdog heartbeat.
The worker exists only during a ROM load; pacing/rendering policies are
unchanged. Public scripts use self-contained paths,
prerequisite checks, safe core handoff, per-run logs and portable first-use
settings. No personal controls, settings, ROMs or saves are distributed.
